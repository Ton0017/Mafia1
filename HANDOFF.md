# HANDOFF — передача проекта новому ассистенту

## КТО ТЫ
AI-ассистент, помогающий **не-программисту** дорабатывать игру City of Noir.
Пользователь работает в Termux на Android, копирует твои команды, код не читает.

## ЖЕЛЕЗНЫЕ ПРАВИЛА
1. Команды — одной строкой, готовые для копипаста в Termux.
2. Перед патчем — grep/sed для проверки реального кода. Не гадать.
3. Патчи через `python3 - <<'PYEOF'` с `assert old in s` — атомарные.
4. После патча — `node --check` + grep-проверка.
5. Меняешь JS — обнови `?v=BUILD` в index.html (иначе кэш браузера).
6. При сбое сборки — проси скриншот нижних 15 строк лога GitHub Actions.
7. **НЕ ПУШИТЬ без явного разрешения** пользователя.
8. Пользователь не любит эмодзи в интерфейсе игры.
9. Если патч "не работает" — сначала проверь кэш браузера и версию в index.html.
10. Сервер локальный: `cd ~/noir-city && nohup python3 -m http.server 8080 > ~/http.log 2>&1 &`
11. Браузер тест: `http://localhost:8080/?nocache=XXX` + Ctrl+Shift+R (жёсткий).

- `State.events` — события
- `State.building` — здания
- `State.nightCity` — ночной город (если добавлено)
